# Engenharia de Prompt e Aplicações em IA

Repositório de atividades acadêmicas sobre a criação e avaliação de prompts para sistemas de IA. Os registros mostram como contexto, instruções e formato da resposta influenciam o resultado, além de exercícios de programação assistida por IA.

## Conteúdo

| Arquivo | O que contém |
| --- | --- |
| [Aula 03](aula03.md) | Registros visuais e reflexão sobre tokenização e limites de contexto |
| [Aula 04](aula04.md) | Comparação de respostas e efeito da definição de persona |
| [Aula 05](aula05.md) | Análise de contexto e instruções a partir do filme *Her* |
| [Notebook de programação assistida](aula07progamacaossistidaporai1.ipynb) | Exercícios em formato Jupyter |
| [Aula 08](aula08) | Registro de prompts e scripts Python para tarefas de automação |

## Tecnologias e formatos

Markdown para os relatórios, Jupyter Notebook e Python para os exercícios de programação. Os exemplos foram produzidos em contexto de estudo e devem ser revistos antes de uso fora de um ambiente de teste.

## Como consultar

```bash
git clone https://github.com/joaoteixeirapedro/engenharia_de_prompt_aplicacoes_Ai.git
cd engenharia_de_prompt_aplicacoes_Ai
```

Abra os arquivos `.md` no GitHub ou em um editor Markdown. Para o notebook `.ipynb`, use JupyterLab, Jupyter Notebook ou Google Colab. O repositório não fornece `requirements.txt`, portanto dependências adicionais devem ser verificadas nas células antes de executar. O arquivo `aula08` reúne texto explicativo e trechos de código; leia e separe o exercício desejado antes de executá-lo, especialmente o organizador de arquivos, que move arquivos no diretório escolhido.
